WanderStay

WanderStay is a full-stack accommodation discovery platform that enables users to search, explore, and manage property listings across different countries. 
The platform provides a seamless experience for travelers to discover unique stays while offering hosts the ability to create and manage listings through a secure and intuitive interface.

Features:

- User registration and login
- Authentication and authorization
- Create, edit, and delete property listings
- Upload and manage property images
- Country-based accommodation search
- Category-based property filtering
- Interactive map integration for location visualization
- Detailed property information pages
- Review and rating system
- AI-powered chatbot for user assistance
- Responsive design for mobile and desktop devices
- Secure user session management
- Dynamic listing management
- Modern and user-friendly interface

Technologies Used:

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB
- EJS
- Bootstrap
- Cloudinary
- Map Integration API
- AI Chatbot Integration
- Git & GitHub

Future Scope:

- Property booking and reservation system
- Wishlist functionality
- Personalized recommendations
- Advanced search filters
- Payment gateway integration
- Multi-language support
